# Security policy

QuietWard Response is in active foundation development. Please do not open public issues for suspected vulnerabilities. Report them privately through GitHub's **Security → Report a vulnerability** flow for this repository.

Include the affected revision, reproduction steps, impact, and any suggested mitigation. Do not include real customer telemetry, credentials, malware, or destructive proof-of-concept payloads.

Phase 1 has no endpoint-action capability. It intentionally provides no shell, process termination, firewall, isolation, deletion, or quarantine endpoint. See `docs/threat-model.md` for trust boundaries and known risks.
